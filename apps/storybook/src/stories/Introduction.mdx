# Maya Numerals

Stories for [`@mayan-numerals/core`](https://www.npmjs.com/package/@mayan-numerals/core), which renders any number as [Maya numerals](https://en.wikipedia.org/wiki/Maya_numerals) in SVG.

- **Number Builder**: type any number in the `value` control and adjust every `toSvg` option.
- **Digits**: every digit from 0 to 19.

Dots are ones, bars are fives and a shell is zero. Levels stack in base 20 with the most significant on top. Fractions continue below a dashed line, and negatives get a minus mark.

For downloads and shareable links, use the [playground](../playground/) in the docs.
